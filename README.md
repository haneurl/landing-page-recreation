# Mixland Landing Page Recreation

Open `index.html` directly in a browser. The page uses plain HTML, CSS, and JavaScript; no build step is needed.

The supplied Figma export has a 1600 × 5487 canvas, but its embedded artwork directory is empty. The three product-preview areas therefore load image files from the public Mixland demo (`mixland.vercel.app`). An internet connection is needed for those previews and the DM Sans web font. If the reference assets are unavailable, the copy and layout still render, but those image areas will be incomplete.

The screen recording could not be inspected frame by frame in this session because the desktop viewer stopped on its browser URL safety check. The layout and copy were mapped from the Figma thumbnail and checked against the publicly available Mixland page. This is a close recreation, not a verified pixel match. Details too small to read in the supplied thumbnail were not transcribed as exact.
