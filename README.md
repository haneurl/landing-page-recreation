# Mixland Landing Page Recreation

A responsive recreation of the Mixland landing page, built using HTML, CSS, and JavaScript.

## Features

- Responsive landing page layout
- Hero section and feature highlights
- Pricing plans and call-to-action section
- Footer and supporting content

## Technologies

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Make sure you have an internet connection to load externally hosted images and the DM Sans font.
